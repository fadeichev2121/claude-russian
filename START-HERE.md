# Claude на русском — пакет 1.3.0

Этот пакет меняет оригинальное установленное приложение. Отдельную русскую копию создавать не нужно.

## Как запустить локальный пакет

Распакуй архив. Открой Терминал в распакованной папке `claude-russian`.

На macOS:

```bash
bash install.sh
```

На Windows открой PowerShell в этой папке:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\windows\install.ps1
```

На Linux:

```bash
bash linux/install.sh
```

Для нестандартной установки добавь `--app "/путь/к/приложению"` на macOS/Linux или `-AppPath 'C:\путь\к\приложению'` в Windows. Для Antigravity Linux укажи папку официальной сборки, если она находится вне `/opt/Antigravity`.

## Что выбрать

```text
1) Установить русский интерфейс
2) Статус / совместимость
3) Откат
4) Включить автовосстановление после обновлений
5) Выключить автовосстановление
6) Статус автовосстановления
7) Проверить обновление сейчас
0) Выход
```

Закрой приложение и дождись завершения его обновления. Сначала установи перевод пунктом **1**, затем включи автовосстановление пунктом **4**. Меню объяснит изменение подписи, если оно требуется. Установщик сам запросит права для выбранного действия, когда это предусмотрено платформой.

После обновления проверка ждёт закрытия приложения, проверяет точную совместимость и сохраняет отдельную резервную копию. Неизвестная сборка ожидает опубликованного профиля. На системной установке Linux и других защищённых папках фонового доступа может не хватить: статус **6** покажет причину, а **7** позволяет выполнить проверку и применить патч вручную.

Откат **3** сначала выключает автовосстановление. Пункт **5** сохраняет установленный перевод и копии. Настройки, пакеты и резервные копии находятся вне приложения; удаление этой распакованной папки после включения не удаляет их.

Этот пакет доступен в репозитории GitHub и в разделе Releases. Команды скачивания из README получают текущие опубликованные установщики. Реальные фоновые службы и восстановление после настоящего обновления ещё не проверены; локальные проверки описаны в [README](README.md).
