# Claude на русском — macOS, Windows и Linux

Перевод интерфейса Claude Desktop: настройки, меню, подсказки, общий доступ и страницы артефактов. Патч изменяет **оригинальную установленную программу** и сохраняет исходные файлы для отката. Отдельная русская копия не создаётся.

**Пакет 1.3.0:** добавлено включаемое автовосстановление перевода после обновлений для macOS, Windows и Linux. [Локальные проверки новой функции](docs/verification/auto-reapply-1.3.0.json): **74 из 74**, с временными тестовыми файлами и имитацией планировщика. Реальные фоновые службы и обновление Claude пока не проверены.

Для предыдущего **пакета 1.2.1** установщики Windows/Linux проверены на настоящих системах — **20 из 20 вариантов прошли**, по пять версий каждой платформы на x64 и ARM64. Исправлены резервные папки Windows и совместимость загрузчика с PowerShell 7. [Отчёт и границы проверки](docs/native-installer-checks.md). Список поддерживаемых выпусков составлен **по состоянию на 4 октября 2026 года**; прежние профили сохранены. Запуск изменённого Claude и вход в аккаунт отдельно не проверялись.

## Совместимость

| Система | Исходная версия Claude | Поддерживаемая установка |
| --- | --- | --- |
| macOS | **2.19675.0**, **2.16120.0**, **2.9939.4**, **2.9939.2**, **2.7032.0**; сохранена **1.46388.4** | Официальный `/Applications/Claude.app`, universal Intel/Apple Silicon |
| Windows | **2.19675.0**, **2.16120.0**, **2.9939.4**, **2.9939.2**, **2.7032.0**, x64 и ARM64 | Обычная установка через **EXE/Squirrel**, папка `app-<версия>` |
| Linux | **2.9939.4**, **2.7032.0**, **2.2553.13**, **2.2553.1**, **2.2553.0**, amd64 и arm64 | Официальный **DEB-пакет**, `/usr/lib/claude-desktop` |

Список последних релизов macOS/Windows определяется официальным каналом обновлений Anthropic и [журналом выпусков](https://claude.com/docs/cowork/changelog). Для Linux берутся последние доступные версии из [официального APT stable](https://downloads.claude.ai/claude-desktop/apt/stable/dists/stable/main/binary-amd64/Packages.gz): он может обновляться позже, поэтому списки различаются. Установщик сам выбирает профиль установленной сборки; выбирать номер версии вручную не нужно.

Точный SHA-256 исходного архива проверяется вместе с версией. На Windows дополнительно проверяются EXE и нативный каталог, на Linux — нативный каталог. Другая сборка с тем же номером, неизвестное изменение или новая версия отклоняются до замены файлов. Контроль совместимости не отключается.

На всех платформах нужен **Python 3.9+**, интернет для скачивания исходников патча и свободное место для резервных копий. В репозитории нет приложения Claude, его бинарных файлов, профиля или истории чатов.

## macOS: быстрый старт

Полностью выйди из Claude через **Cmd+Q**, затем выполни в Терминале:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/claude-russian/main/install.sh -o claude_ru.sh
bash claude_ru.sh
```

Выбери **1 — Установить русский интерфейс**. Меню объяснит изменение подписи и запросит согласие. Если нужны права администратора, оно само запросит пароль. После установки открой обычный Claude из папки «Программы».

Нужны штатные `codesign`, `ditto` и Xcode Command Line Tools. Если инструменты отсутствуют: `xcode-select --install`.

На macOS сохраняется **полный исходный Claude.app**, включая официальную подпись. После изменения приложение получает локальную ad-hoc подпись и исключение `com.apple.security.cs.disable-library-validation`. Это ослабляет проверку происхождения библиотек. Возможны повторный вход и новые системные разрешения; работа Cowork, Claude Code и всех системных интеграций после изменения подписи отдельно не подтверждена. Откат восстанавливает полный исходный пакет.

## Windows: быстрый старт

Нужны Windows, PowerShell 5.1+ и Python с [python.org](https://www.python.org/downloads/windows/). Псевдоним Python, который открывает Microsoft Store, не подходит.

Поддерживается **обычная EXE-установка Claude**. Пакеты **MSIX / Microsoft Store / WindowsApps не поддерживаются**: их файлы защищены механизмом установки Windows. Патч не меняет владельца WindowsApps и не перепаковывает MSIX. Если у тебя эта установка, сначала самостоятельно выбери обычный официальный EXE; автоматической замены установленного приложения нет. Ссылки Anthropic: [EXE x64](https://api.anthropic.com/api/desktop/win32/x64/exe/latest/redirect), [EXE ARM64](https://api.anthropic.com/api/desktop/win32/arm64/exe/latest/redirect). Они ведут на актуальный релиз, который может отличаться от версии в таблице.

Полностью выйди из Claude, включая значок в области уведомлений. Открой **PowerShell** из своего обычного аккаунта:

```powershell
Invoke-WebRequest -Uri 'https://raw.githubusercontent.com/fadeichev2121/claude-russian/main/windows/install.ps1' -OutFile 'claude_ru.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1
```

Выбери **1**. `ExecutionPolicy Bypass` действует только для запуска этого процесса; системная политика выполнения не меняется.

Установщик ищет `app-*` внутри `%LOCALAPPDATA%\AnthropicClaude` и `%LOCALAPPDATA%\Claude`. Если папка другая, укажи ту, где лежат `claude.exe` и `resources`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 -AppPath 'C:\путь\к\Claude\app-2.19675.0'
```

Windows-вариант сохраняет исходные **три заменяемых файла**: `resources/app.asar`, `resources/en-US.json`, `claude.exe`. Он обновляет существующий ресурс контроля ASAR внутри EXE, сохраняя настройки Electron fuses. **Цифровая подпись Authenticode Anthropic становится недействительной**, потому что EXE изменён. До установки меню запросит согласие. Откат возвращает исходные байты EXE и его подпись. Установщик не отключает SmartScreen, Defender или контроль пакетов; запуск изменённого EXE в твоей системе ещё не подтверждён.

Для осознанного автоматизированного запуска можно передать явное согласие `-ApproveExeSignature`:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 install -ApproveExeSignature
```

Этот параметр означает согласие на описанное изменение подписи EXE. Без него установщик спрашивает подтверждение в терминале и отказывается принимать согласие из перенаправленного ввода. Поддерживаются PowerShell 5.1 и 7.

Права администратора автоматически не запрашиваются. Если Windows отклоняет запись в обычную папку Claude, сообщение предложит повторить запуск из терминала администратора. Для WindowsApps это не решение — такие установки отклоняются.

## Linux: быстрый старт

Поддерживается официальный DEB для amd64/arm64. Anthropic описывает Linux-версию как beta для Ubuntu 22.04+ и Debian 12+: [официальная инструкция](https://code.claude.com/docs/en/desktop-linux). AppImage, Snap, Flatpak, Wine и сторонние сборки здесь не поддерживаются.

Полностью выйди из Claude и дождись завершения обновления пакетов. В обычном пользовательском терминале:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/claude-russian/main/linux/install.sh -o claude_ru_linux.sh
bash claude_ru_linux.sh
```

Выбери **1**. Для файлов в `/usr/lib/claude-desktop` меню запросит `sudo` только на выбранное действие. Само меню и загрузка работают без root.

Патч сохраняет исходные **два заменяемых файла**: `resources/app.asar` и `resources/en-US.json`. Исполняемый файл, sandbox, настройки apt и репозитории пакетов не меняются. При замене ресурсов сохраняются их исходные владелец и права. Обновление DEB может заменить перевод. Пункт **4** включает повторные проверки; для защищённой системной папки потребуется ручное применение пунктом **7** с запросом sudo.

## Меню и откат

На всех платформах одинаковые пункты:

```text
1) Установить русский интерфейс
2) Статус / совместимость
3) Откат
4) Включить автовосстановление после обновлений
5) Выключить автовосстановление
6) Статус автовосстановления
7) Проверить обновление сейчас
0) Выход
```

Для отката полностью закрой Claude и выбери **3**. Этот пункт сначала выключает автовосстановление, затем восстанавливает текущую сборку по её совпадающей записи. Старый backup не записывается поверх обновлённого Claude. Можно сразу указать действие:

```bash
# macOS
bash claude_ru.sh status
bash claude_ru.sh restore

# Linux
bash claude_ru_linux.sh status
bash claude_ru_linux.sh restore
```

```powershell
# Windows
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 status
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 restore
```

| Система | Состояние и резервные копии по умолчанию |
| --- | --- |
| macOS | `~/Library/Application Support/claude-russian/state` |
| Windows | `%LOCALAPPDATA%\claude-russian\state` |
| Linux | `~/.local/state/claude-russian` |

Сохрани папку состояния, пока нужен откат. Профиль и чаты установщик не меняет. На Mac текущая программа с патчем при откате сохраняется в скрытой папке рядом с приложением. На Windows/Linux в резервной папке сохраняются оба варианта каждого заменённого файла — исходный и подготовленный с переводом.

Если установка Windows/Linux прервалась после частичной замены файлов, штатный откат допускает смесь сохранённых исходных и изменённых файлов. Если обновление или другая программа записала неизвестные байты, автоматическая перезапись останавливается. Это сохраняет чужие изменения, но может потребовать восстановить официальный Claude обычным способом.

## После обновления Claude

Обновление заменяет файлы приложения и может убрать перевод. Чтобы возвращать его автоматически, скачай актуальный установщик и выбери **4 — Включить автовосстановление**. На macOS и Windows потребуется явное согласие на изменение подписи новых поддерживаемых сборок. Включение создаёт расписание только для текущего пользователя; обычная установка пунктом **1** его не создаёт.

```bash
# macOS: спросит согласие на локальную подпись
bash claude_ru.sh auto-enable

# Linux
bash claude_ru_linux.sh auto-enable
```

```powershell
# Windows: спросит согласие на изменение подписи EXE
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 auto-enable
```

Проверка запускается раз в 2 минуты и ждёт закрытия Claude и завершения обновления. Новая исходная сборка должна совпасть в двух проверках с интервалом не меньше минуты. После этого перевод применяется с отдельной резервной копией для её содержимого и пути установки. На Windows обнаруживается новейшая числовая папка `app-*`, даже если ранее был указан путь к старой версии.

Не чаще раза в сутки скачиваются опубликованные исходники этого репозитория, привязанные к конкретному commit SHA. Они могут содержать новые проверенные профили совместимости. Без сети ранее поддерживаемая сборка продолжает использовать сохранённый пакет. **Неизвестная сборка остаётся нетронутой и ожидает подходящего профиля.** Пять последних выпусков — список на дату этой ревизии, а не гарантия поддержки будущих обновлений. Проверки версии и контрольных сумм остаются обязательными.

На macOS работает пользовательский LaunchAgent, на Windows — задача текущего пользователя, на Linux — таймер `systemd --user`. Фоновая проверка не запрашивает пароль, не получает повышенные права и не завершает Claude. Если папка приложения недоступна для записи, статус сообщает, что нужно применить перевод вручную. Это обычно касается установленного системного DEB в `/usr/lib/claude-desktop`; для защищённой установки Windows также понадобится ручной запуск с правами администратора. Не меняй права приложения ради фоновой установки.


Проверка расписания начинается сразу после включения и продолжает выполняться после входа в систему. Если остановка системного расписания не удалась, выключенный флаг в настройках всё равно блокирует новое применение; меню покажет причину, а ручной откат останется доступным.

Пункт **5** выключает расписание, сохраняя перевод и резервные копии. Пункт **6** показывает последнее состояние. Пункт **7** запускает проверку сейчас с теми же проверками совместимости и ожиданием стабильной сборки; на macOS/Linux этот явно выбранный пункт может запросить пароль только для применения перевода. На Windows при отказе в доступе нужно выполнить показанную команду вручную из терминала администратора. Те же действия доступны как `auto-disable`, `auto-status`, `auto-check`. Пункт **3** выключает автоматическое восстановление до отката, чтобы перевод не установился снова.

| Система | Служебная папка автовосстановления |
| --- | --- |
| macOS | `~/Library/Application Support/claude-russian/auto` |
| Windows | `%LOCALAPPDATA%\claude-russian\auto` |
| Linux | `~/.local/share/claude-russian/auto` |

Пакеты, настройки, результаты проверок и отдельные состояния каждой сборки хранятся здесь, вне приложения. Для нестандартного расположения есть `--control-dir` (`-ControlDirectory` в PowerShell). `--state-dir` / `-StateDirectory` при включении добавляет уже существующее состояние перевода; новые сборки получают отдельные папки внутри `auto`. Не удаляй эти папки, пока нужен откат.

### Если автовосстановление не включено

Заверши старое меню пунктом **0**, заново скачай установщик и проверь **2 — Статус**. Поддерживаемые версии из таблицы распознаются автоматически; для неизвестной сборки дождись нового профиля, не обходи сообщение о несовместимости.

Если прежний патч уже заменён обновлением, его старые резервные копии не перезаписываются. Для новой поддерживаемой исходной установки используй **отдельную папку состояния**. На Windows также явно укажи новую `app-*` папку:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\claude_ru.ps1 -AppPath 'C:\путь\к\Claude\app-2.19675.0' -StateDirectory "$env:LOCALAPPDATA\claude-russian\state-2.19675.0"
```

```bash
# macOS
bash claude_ru.sh menu --state-dir "$HOME/Library/Application Support/claude-russian/state-2.19675.0"

# Linux
bash claude_ru_linux.sh --state-dir "$HOME/.local/state/claude-russian-2.9939.4"
```

При последующем статусе/откате указывай те же пути. Не выбирай папку состояния внутри приложения или установщика.

На Mac фоновый мост Chrome `chrome-native-host` не блокирует установку. Для обновляющего компонента `ShipIt` предусмотрено ожидание до 30 секунд; если обновление продолжается, повтори действие позже. На Windows/Linux обнаруженное приложение или обновление останавливает действие. Процессы автоматически не завершаются.

## Что переводится и что проверено

В словаре **3608 записей интерфейса** и **642 записи нативного каталога**. В новых версиях применяются только нативные ID, которые ещё существуют: новые и неизвестные строки сохраняются. Некоторые новые экраны, серверные подписи и описания сторонних навыков могут оставаться на английском. Названия продуктов, моделей и технические команды сохраняются.

Перевод выполняется локально по словарю, без сервиса машинного перевода. Сообщения, код, редактируемые поля и пользовательские названия исключены из перевода. Язык ответов Claude и голосового общения настраивается отдельно.

Пользователь подтвердил работу предыдущего перевода на Mac. **5 октября 2026 года все 20 Windows/Linux профилей прошли [нативный прогон](https://github.com/fadeichev2121/claude-russian/actions/runs/37261832045)**: применение перевода, повторная установка, обновление через откат/установку, отказ при повреждениях, точное восстановление исходных файлов и отдельный запуск установщика с загрузкой исходников из GitHub. Для Windows проверены PowerShell 5.1/7, для Linux — sudo и сохранение владельца/прав. [Подробности и JSON-отчёт](docs/native-installer-checks.md). Проверки выполнялись на временных файлах официальных сборок. **Запуск Claude, вход, Cowork, Claude Code и полнота перевода всех экранов остаются непроверенными.** Нового прогона macOS в этой ревизии не было.

Для пакета **1.3.0** отдельно прошли **74 проверки автовосстановления** на временных файлах. Реальные LaunchAgent, Windows Task Scheduler и systemd timer не включались; их работа и повторный перевод после настоящего обновления пока не подтверждены. Предыдущий нативный прогон выше относится к установщикам **1.2.1**. [Отчёт новой функции](docs/verification/auto-reapply-1.3.0.json).

Пропущенную фразу сообщай через [issue](https://github.com/fadeichev2121/claude-russian/issues): система, версия, раздел и английский текст. Скрой почту, имена, чаты и идентификаторы на скриншоте.
