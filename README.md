# Claude на русском — macOS

Локальный перевод интерфейса Claude Desktop **1.46388.4**: настройки, меню, подсказки, диалоги общего доступа и страницы артефактов. Патч применяется к установленному **`/Applications/Claude.app`** после сохранения полной резервной копии. После установки ты открываешь привычный Claude из папки «Программы».

## Быстрый старт

1. Полностью закрой Claude через **Cmd+Q**.
2. Открой **Терминал** и выполни по очереди:

```bash
curl -fL https://raw.githubusercontent.com/fadeichev2121/claude-russian/main/install.sh -o claude_ru.sh
bash claude_ru.sh
```

3. Выбери **1 — Установить русский интерфейс**. Перед установкой прочитай объяснение изменения подписи приложения и подтверди согласие в терминале.
4. После завершения снова открой **Claude.app** из `/Applications` — обычной папки «Программы».

Если для изменения приложения не хватает прав, меню само запросит повышение прав. Пароль администратора вводится в терминале; символы при вводе не отображаются.

## Меню в терминале

```text
==== Русский интерфейс Claude для macOS ====
1) Установить русский интерфейс
2) Статус / совместимость
3) Откат
0) Выход
```

| Пункт | Что происходит |
| --- | --- |
| **1 — Установить** | Проверяются исходная сборка и закрытое приложение; сохраняется полная резервная копия, затем патч применяется к Claude.app. |
| **2 — Статус / совместимость** | Показываются версия, соответствие поддерживаемому архиву и состояние установки. Приложение не изменяется. |
| **3 — Откат** | Из резервной копии восстанавливается исходный Claude с исходной подписью. Приложение с патчем сохраняется в папке восстановления. |
| **0 — Выход** | Установщик закрывается. |

Те же действия можно выбрать сразу командой:

```bash
bash claude_ru.sh install
bash claude_ru.sh status
bash claude_ru.sh restore
bash claude_ru.sh --help
```

## Требования и совместимость

- **macOS** и установленный официальный Claude Desktop **1.46388.4** в `/Applications/Claude.app`.
- **Python 3.9 или новее**, доступный командой `python3`.
- Штатные утилиты macOS `codesign` и `ditto`, а также **Xcode Command Line Tools**. Если установщик сообщает об отсутствии инструментов, выполни `xcode-select --install` и дождись завершения установки.
- Интернет для загрузки установщика и файлов патча; место на диске для полной резервной копии и подготовки изменённого приложения.

Установщик проверяет **номер версии и SHA-256 исходного `app.asar`**. Одинаковый номер версии сам по себе не гарантирует совместимость. Другая сборка, уже изменённый архив или новая версия будут отклонены до применения патча.

Windows и Linux этим установщиком не поддерживаются. Приложение Claude, его исполняемые файлы и профиль пользователя в репозитории не распространяются.

## Что изменится в приложении

Изменение файлов установленного Claude требует заменить подпись Anthropic **локальной ad-hoc подписью**. После применения патча твой `/Applications/Claude.app` будет локально изменённым приложением с неофициальной подписью.

Добавляется исключение `com.apple.security.cs.disable-library-validation`: оно ослабляет проверку происхождения загружаемых библиотек. У локальной подписи также нет доступа к специальным группам Keychain, связанным с сертификатом Anthropic. Поэтому при запуске могут потребоваться **повторный вход и новые системные разрешения**. Установщик объясняет эти последствия и запрашивает согласие до изменения приложения.

Перед применением сохраняется полный исходный пакет Claude, включая официальную подпись. Штатный откат восстанавливает этот пакет целиком. Работа всех функций Claude Code, Cowork и системных интеграций после изменения подписи отдельно не подтверждена.

## Как вернуться к обычному Claude

1. Закрой Claude через **Cmd+Q**.
2. Выполни `bash claude_ru.sh restore` либо выбери **3 — Откат** в меню.
3. Снова открой **Claude.app** из `/Applications`.

Резервная копия `backup-<идентификатор>.app` и запись установки находятся здесь:

```text
~/Library/Application Support/claude-russian/state
```

При откате исходный пакет восстанавливается из резервной копии целиком, вместе с исходной подписью. Текущий пакет с патчем сохраняется в скрытой папке рядом с приложением, обычно `/Applications/.claude-russian-transaction-<идентификатор>/recovery-patched.app`; он не удаляется. Точный путь выводится в терминале и в статусе. В скрытой папке подготовки также сохраняется исходный пакет.

Профиль и история чатов остаются на месте. Не удаляй данные Claude ради отката и сохрани папку состояния, пока нужен автоматический возврат. Если файлы приложения изменились после установки, установщик может остановиться, чтобы сохранить эти изменения.

## Вопросы и ограничения

**Переведено абсолютно всё?**  
В словаре **3608 записей интерфейса** и **642 перевода нативного каталога**. Переводятся известные строки: новые экраны, изменившиеся серверные подписи и описания сторонних навыков могут остаться на английском. Названия продуктов, моделей и технические команды сохраняются.

**Будут ли переводиться мои чаты и код?**  
Переводчик исключает сообщения, код, редактируемые поля и пользовательские названия. Он работает локально по словарю, без сервиса машинного перевода. Язык ответов Claude и голосового общения настраивается отдельно.

**Что будет после обновления?**  
Обновление может убрать патч. Автоматического повторного применения нет: для новой сборки нужна отдельная адаптация. Не устанавливай старый патч поверх несовместимого приложения.

**Патч уже установлен?**  
Используй **2 — Статус / совместимость**. Запись состояния позволяет установщику распознать свою установку. Изменения, сделанные другой программой или прежним локальным патчем, могут оказаться несовместимыми; неизвестные файлы не перезаписываются.

**Claude закрыт, но установщик просит закрыть его?**  
Начиная с пакета **1.0.1**, фоновый мост `chrome-native-host`, который Chrome оставляет после закрытия Claude, не блокирует установку. В пакете **1.0.2** для компонента обновления `ShipIt` добавлено ожидание до **30 секунд**. Если обновление ещё работает, установщик попросит повторить действие позже; если открылся основной Claude, его нужно закрыть через Cmd+Q. Установщик не завершает процессы автоматически и не применяет патч одновременно с обнаруженным обновлением.

Чтобы получить новую проверку, заверши старое меню пунктом **0**, заново скачай и запусти установщик командами из «Быстрого старта». Если работает другой компонент Claude, сообщение укажет его имя и PID.

**Как сообщить о пропущенном переводе?**  
Создай [issue](https://github.com/fadeichev2121/claude-russian/issues) с версией приложения, названием раздела и английской фразой. Перед публикацией снимка скрой почту, имена, содержимое чатов, идентификаторы и другие личные данные.

**Как проверялось?**  
Пользователь подтвердил работу перевода на своём Mac. Публичный установщик для изменения установленного Claude подготовлен отдельно; его установка и откат ещё не подтверждены. Это не гарантия полного перевода всех функций.

## Для разработчиков

Основные файлы в `macos/`:

| Файл | Назначение |
| --- | --- |
| `patch.py` | Совместимость, полная резервная копия, применение к Claude.app, локальная подпись, состояние и откат. |
| `ru.json` | Словарь основного интерфейса. |
| `native-ru.json` | Переводы нативных строк по идентификаторам. |
| `ui-runtime.js` | Перевод известных текстовых узлов и подсказок с исключениями для пользовательского содержимого. |
| `catalog.py` | Подготовка фраз с переменными, числами и ссылками. |
| `asar.py` | Обновление архива оболочки и его контрольных сумм. |

Состояние хранится в `~/Library/Application Support/claude-russian/state`. При повышении прав учитывается исходный пользователь. Рабочая подготовка пакета выполняется внутри установщика; итоговый путь приложения остаётся `/Applications/Claude.app`.
